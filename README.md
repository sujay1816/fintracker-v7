# FinTracker - Personal Finance Dashboard

A beautiful, responsive finance tracking web application built with React, Tailwind CSS, and Recharts.

## Features

- 📊 **Dashboard** - Overview of income, expenses, health score, charts
- 💰 **Income** - Track monthly income by source
- 💸 **Expenses** - Track one-time and recurring expenses
- 📈 **Investments** - Track investments across multiple types
- 🎯 **Goals** - Set and track financial goals with progress
- 📊 **Budgets** - Set category budgets with alerts
- 🏆 **Gamification** - XP, levels, and streaks
- 💾 **Auto-save** - Data saved to localStorage automatically

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deploy

### Vercel (Recommended)
1. Push to GitHub
2. Import project in Vercel
3. Deploy!

### Netlify
1. Run `npm run build`
2. Drag & drop `dist` folder to Netlify

### Manual
1. Run `npm run build`
2. Upload `dist` folder to any static host

## Tech Stack

- React 18
- Tailwind CSS
- Recharts (charts)
- Lucide React (icons)
- Vite (build tool)
